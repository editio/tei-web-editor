      How it works
      
          
        
            
      • Your document is checked while you type. The first indicator turns green when the XML is well-formed; the second when it is valid against TEI All.
        • 
            
      • Errors are underlined in red. Hover over them, or open the Problems tab and click an error to jump to it.
        • 
            
      • Type < to see the elements allowed at that point. Type a space inside a start tag to see its attributes. Inside ref="" you get the xml:ids defined in your document.
        • 
            
      • Hover over a tag name to read its definition from the TEI Guidelines.
        • 
            
      • Drag the bar between the editor and these panels to resize them (double-click it to reset).
        • 
            
      • Your work is saved in this browser only. Click Download to keep a copy or hand it in.
        • 
          
      
          
      Keyboard shortcuts
      
          
      
            
      Ctrl/Cmd + ESurround the selection with an element
      
            
      Ctrl + SpaceShow suggestions
      
            
      Alt + Shift + DSplit element at the cursor
      
            
      Ctrl/Cmd + Shift + FFormat and indent
      
            
      Ctrl/Cmd + /Comment / uncomment
      
            
      Ctrl/Cmd + FFind and replace
      
            
      Ctrl/Cmd + ZUndo
      
            
      Ctrl/Cmd + SDownload the file
      
          
      
          
      About
      
          
      Validation runs entirely in your browser against the TEI All Relax NG schema (). Nothing is sent to a server. Schematron rules embedded in TEI All are not checked.
